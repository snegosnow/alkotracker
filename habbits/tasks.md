# habbits — задачи реализации

Основа задач — [PRD.md](PRD.md), [SPEC.md](SPEC.md), [PLAN.md](PLAN.md) и [design.md](design.md).

## Порядок работы

- Выполнять один этап за раз. Начинать этап после подтверждения пользователя.
- После каждого действия обновлять соответствующий пункт и журнал действий в этом файле.
- Отмечать выполненные пункты через `[x]` после проверки результата. Частично выполненные пункты оставлять с `[ ]` и пояснять оставшуюся работу.
- По завершении этапа записывать результат проверок, сообщать пользователю итог и ожидать подтверждения на следующий этап.
- При блокировке указывать причину и оставшиеся задачи. Продолжать доступные задачи текущего этапа.

Текущий статус — локальная реализация этапов 2–7 выполнена в доступном объёме. Для облачного подключения ожидаются данные Turso и почтового сервиса.

Проверка 25.11.2026 — habbits использует статистику алкоголя и табака, журнал покупок, авторизацию и облачную базу Turso. Отправка писем для восстановления пароля ещё не настроена.
